# Ngữ cảnh dự án ASR Studio

ASR Studio là app macOS chép lời tiếng Việt tại máy và tạo bản nháp biên bản bằng nhà cung cấp AI do người dùng chọn. Phần xử lý viết bằng Rust, app dùng Tauri 2 và giao diện dùng TypeScript thuần với Vite.
